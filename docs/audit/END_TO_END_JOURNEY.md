## ETAPAS QUE NÃO PASSAM HOJE (com motivo)

1. **Vincular proprietário com mídia** — bug de serialização (Date vs string) no Postgres real. Corrigível em ~1 linha (normalizar DTO).
2. **CHARGE → PAID em processos separados com fake** — limitação do fake por-processo (não é defeito; exige provider real ou execução in-process).
3. **Criar campanha Meta via HTTP sem idempotencyKey** — contrato exige o campo; o fluxo do produto usa MCP (que envia).
4. **Assinatura no processo `index.ts` padrão** — sem credencial → 400 "não configurado" (seguro; para dev é preciso injetar fake via launcher, como os testes fazem).
