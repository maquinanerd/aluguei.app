# 07 — Responsive & Accessibility

## Breakpoints comportamentais
- 360–479 mobile
- 480–767 large mobile
- 768–1023 tablet
- 1024–1439 desktop
- 1440+ desktop XL

## Sidebar
desktop: full sidebar.
tablet/mobile: drawer.
Não espremer sidebar.

## Inspector
desktop: contextual rail 300–360.
mobile: sheet/drawer.

## Tables
desktop: dense table.
tablet: colunas prioritárias.
mobile: list rows/cards operacionais quando necessário.

## Toolbar
mobile: primary action + overflow.

## Accessibility
- labels;
- field descriptions;
- aria-invalid;
- keyboard;
- logical tab order;
- focus visible;
- escape em overlays;
- focus trap em modal;
- aria-live em async/AI;
- reduced motion;
- contrast AA;
- status não apenas por cor;
- action icons críticos com label/tooltip.

## Vistorias/field
Flows usados em campo devem considerar:
- touch targets;
- câmera;
- áudio;
- conexão instável;
- retry;
- feedback persistente.
