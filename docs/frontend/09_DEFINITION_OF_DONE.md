# 09 — Frontend Definition of Done

Uma rota/tela está pronta quando:

- capability real mapeada;
- endpoint/contracts reais;
- RBAC;
- UI PEG;
- responsive;
- loading;
- skeleton quando justificável;
- empty;
- first use;
- error;
- permission denied;
- disconnected integration quando aplicável;
- partial data;
- processing;
- retry;
- success;
- warning/blocked quando aplicável;
- keyboard;
- accessibility;
- nenhum secret client-side;
- sem console error;
- sem fake silencioso em produção;
- tests relevantes;
- visual QA;
- P0/P1 = 0.

## Gate da fase
- lint;
- typecheck;
- unit/component tests;
- integration tests;
- E2E crítico;
- build;
- security scan existente;
- visual review;
- docs/state;
- commit.
