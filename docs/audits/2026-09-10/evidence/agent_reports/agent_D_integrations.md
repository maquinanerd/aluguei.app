## 3. Detalhamento por integração

### 3.1 Storage S3/R2

- Interface `StorageService` (`packages/storage/src/types.ts:39-48`): `putObject`, `getObject`, `deleteObject`, `headObject`, `getPresignedPutUrl`, `getPresignedDownloadUrl`.
- Adapter `S3StorageAdapter` (`s3.adapter.ts:45-146`): cliente S3 com `region` default `auto` (`:57`), endpoint/credenciais opcionais (`:58-63`). Sem credenciais explícitas usa a cadeia padrão do AWS SDK (não configurado no código). Timeouts/retries = defaults do SDK (não configurados em `:57-64`).
- Seleção: plugin (`apps/api/src/plugins/storage.ts:25-49`): injeção de teste > `STORAGE_BUCKET` ausente → `null` > S3. Não depende de `NODE_ENV`. `.env.example:13` preenche `STORAGE_BUCKET=aluguei-private`; com endpoint/credenciais vazios o adapter é criado apontando para a AWS com região `auto` (P3, D-40).
- Fake: `FakeStorageService` existe apenas em `tests/integration/src/fakes.ts:4` (não é selecionável em runtime).
- Consumidores: API (upload/confirm/delete de mídia de imóvel e de vistoria). Worker não usa storage.
- Testes: 8 (`s3.adapter.test.ts`).
- Status: PARTIAL (upload implementado; download nunca consumido — seção 7).

### 3.2 Asaas (pagamentos)

- Endpoints e comportamento: seção 2. Timeout 10 s (`asaas.ts:244`); sem retry interno; `retryable` calculado (`:207-211`) mas não lido pelo worker (backoff é por job). User-Agent default (`:245`). Header `access_token` (`:393`).
- Idempotência: cliente find-or-create por `externalReference=aluguei:payer:{document}` (`:345-370`) com cache em memória; `createCharge` não envia chave de idempotência → reexecução cria cobrança nova.
- Registry (`payments/registry.ts:17-28`): override > `FAKE` > `ASAAS`+chave > `null`.
  - API: `PAYMENT_PROVIDER` ausente → `null` → rotas 400 "Pagamento não configurado" (`charges.ts:168-170`, `portal.ts:490-493`). Fail-closed.
  - Worker: `PAYMENT_PROVIDER` ausente → `'FAKE'` (`inboxJobs.ts:178`) mesmo com `NODE_ENV=production`. Fail-open (D-08).
  - Worker não repassa `ASAAS_ENV` (`inboxJobs.ts:177-184`) → D-03.
- Quebras de integração:
