# Evidências do Gate G2 — verificação do orquestrador na árvore integrada

As trilhas A e B1 registraram seus próprios gates (`../track-a/`, `../track-b1/`). Um agente
pode dizer que passou; o orquestrador roda de novo. Esta pasta é essa segunda execução, feita
na árvore integrada `g2/integration` (commit `11fcb2e`: `main` + `ops/storage-db` do PR #2 +
trilha A + Track B1), sem cache e sem nada herdado das trilhas.

Logs desta máquina (Windows 11, Node 24.19, pnpm 11.15.1), sem cores ANSI. Sem efeito externo:
providers FAKE, Meta em dry-run, IA mock, nenhuma credencial. Cada arquivo começa com o comando
e a árvore; os de `test:pg` e Playwright terminam com `# exit=<código>`.
