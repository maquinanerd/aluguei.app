## 4. Conclusão sobre a ordem histórica

A ordem recomendada em 08/2026 (estabilizar → Storage → Asaas → WhatsApp → assinatura → crédito → Meta → portais → Maps → produção) partia de um núcleo "estável". Com os achados atuais, **"estabilização interna" precisa ser redefinida** para incluir P0 financeiros, de tenant e de contrato, e os bloqueios de UI — e **produção/observabilidade mínima precisa vir antes de qualquer dinheiro real**, não por último.
