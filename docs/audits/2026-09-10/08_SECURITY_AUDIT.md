## 4. LGPD / privacidade

- Consentimento `CREDIT_SCREENING` exigido e auditado; `LEAD_IMPORT` registrado no import de canal (PROVADO: 2 consentimentos para 2 leads importados). **Sem revogação** de consentimento via API.
- Dados sensíveis em claro no banco (CPF/CNPJ, conta bancária, retorno de bureau), sem política de retenção/eliminação e sem endpoint de exclusão/anonimização de titular.
- IA: o texto integral da mensagem de WhatsApp vai ao LLM quando um provider real é configurado (`packages/integrations/src/ai/extract.ts:39-42`); Meta: validação impede PII na copy (PROVADO); token Meta nunca vai ao MCP/LLM (código).
- Portal: token de acesso é devolvido ao usuário do backoffice na resposta HTTP (não há canal próprio de entrega).
