# Fronteira de escopo — Aluguei.app

O Aluguei.app é um produto independente.

- Nenhum banco, API interna, catálogo, worker, código ou serviço de outro produto imobiliário é dependência do Aluguei.app.
- Documentos de outros projetos podem existir como referência local, mas não definem requisitos nem arquitetura.
- Somente `AGENTS.md`, `docs/`, `orchestration/`, contratos, testes e código deste repositório são fontes normativas.
- Em caso de conflito, a documentação oficial do Aluguei.app prevalece.
- `planejamento-plataforma-inteligencia-imobiliaria-v2.pdf` é legado de outro produto e não deve ser lido para derivar requisitos do Aluguei.app.
